# Update Status

在一次有意义的实现或 review 后使用。

```text
Update project state for future sessions.

Read:
- docs/plans/active.md
- docs/status.md
- recent diff
- command outputs from this session

Update docs/status.md with:
- current state
- recent changes
- active work
- known risks
- commands run and results
- next recommended action

Constraints:
- Do not claim commands were run unless there is evidence.
- Keep status concise enough for a new session to read quickly.
- Preserve unresolved risks instead of hiding them.

Output:
- Summary of status changes
- Any remaining blockers
```
