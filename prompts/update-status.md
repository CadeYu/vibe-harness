# 更新状态

在一次有意义的实现或 review 后使用。

```text
为未来 sessions 更新项目状态。

读取：
- `docs/plans/active.md`
- `docs/status.md`
- 最近的 diff
- 本 session 的命令输出

更新 `docs/status.md`，包含：
- 当前状态
- 最近变更
- 当前工作
- 已知风险
- 已运行命令和结果
- 建议下一步

约束：
- 没有证据时，不要声称命令已经运行。
- status 要足够简洁，让新 session 能快速阅读。
- 保留未解决风险，不要隐藏。

输出：
- 状态变更摘要
- 剩余阻塞项
```
