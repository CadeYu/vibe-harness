# Harness 简化实验

这个文件记录哪些 harness 组件是承重结构，哪些已经变成多余成本。

## 原则

- 不靠感觉删除规则，用固定 benchmark 对比。
- 一次只移除一个组件。
- 结果退化就恢复，结果不变才保留简化。

## 常见候选

- 过长的根指令。
- 很少触发的 specialist review。
- 重复的状态文档。
- 已被测试或脚本覆盖的手写提醒。
