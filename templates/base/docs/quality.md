# 质量评分

这个文件记录项目是在变强还是变弱。它不是单次 review 结论，而是长期质量快照。

## 评级标准

- A：验证通过，边界清晰，agent 容易接手，测试稳定。
- B：主要路径可用，存在少量文档、测试或边界缺口。
- C：部分可用，有明显风险或不稳定路径。
- D：不可用，或存在严重结构、数据、安全或验证问题。
